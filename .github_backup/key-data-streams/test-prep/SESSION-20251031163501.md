   - Server terminal logs (real-time)

1. Navigate to: `http://localhost:9090/session/canvas/{UserToken}`
2. Perform actions:
   - Join session
   - Type question in input field
   - Click "Submit Question"
   - Vote on a question
   - Observe broadcasted assets
3. Observe:
   - Browser console logs
   - Asset rendering in canvas area
   - Question list updates

#### Scenario C: TranscriptCanvas - Participant Transcript
1. Navigate to: `http://localhost:9090/transcript/canvas/{UserToken}`
2. Perform actions:
   - Join transcript view
