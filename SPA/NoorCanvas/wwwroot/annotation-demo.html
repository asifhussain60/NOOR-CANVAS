Quick Start Guide

IMPORTANT: Testing Laser Pointer Synchronization

You need TWO separate browser windows/tabs to see laser pointer synchronization!

Why? SignalR broadcasts to "other" clients:

  • When you move the laser in View 1, it broadcasts via SignalR
  • SignalR's Clients.OthersInGroup() excludes the sender
  • View 2 in the same browser window won't receive the broadcast
  • Open a second window/tab to act as a different client

Quick Setup:

  1. Window 1: Stay on this page → Click Connect → Activate Laser Pointer
  2. Window 2: Open https://localhost:9091/annotation-demo.html → Click Connect
  3. Test: Move mouse over View 1 in Window 1 → See laser appear in View 2 of Window 2!

Tool Tips

  • Laser Pointer: Move your mouse over View 1 to see a real-time red laser dot synchronized to View 2
  • Draw: Click and drag to create freehand drawings that persist across both views
  • Highlight: Click and drag to create semi-transparent highlight boxes
  • Note: Click to place a note marker and enter text
  • Color Picker: Change annotation colors before drawing
  • Clear All: Remove all annotations from both views

How It Works

Architecture

  • Uses existing noor-annotations.js
  • SignalR AnnotationHub for real-time sync
  • SVG overlay for annotation rendering
  • Persists to canvas.Annotations table

Features

  • Freehand drawing with customizable colors
  • Text highlighting and selection
  • Sticky notes at specific points
  • Real-time broadcasting to all viewers

Better Alternatives for HostControlPanel.razor

For a production implementation in HostControlPanel, consider:

  1. Annotorious - Open-source image annotation library with rich features
  2. Fabric.js - Powerful canvas library with built-in annotation support
