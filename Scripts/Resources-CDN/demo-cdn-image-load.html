ℹ️ How This Works

This page loads images directly from resources.kashkole.com, which is a Cloudflare tunnel pointing to your local IIS server on port 80. The cloudflared process running on your machine creates a secure tunnel to Cloudflare's edge network, making your local resources publicly accessible without opening firewall ports.
