## Problem Statement

**Current Behavior**:
When a host starts a session on HostControlPanel.razor, they choose between:
- **"Asset Share"** → Should route users to `/session/canvas/{token}` (SessionCanvas.razor)
- **"Section Share"** → Should route users to `/transcript/canvas/{token}` (TranscriptCanvas.razor)

However, this selection is:
1. ✅ Tracked locally in `HostControlPanel.selectedCanvasType`
2. ✅ Sent to API endpoint `POST /api/host/session/{sessionId}/start?canvasType={canvasType}`
3. ❌ **NOT persisted to database**
4. ❌ **NOT available when user registers on UserLanding.razor**

**Required Behavior**:
When a user registers on UserLanding.razor during an active session, the app needs to know which canvas type the host selected to route correctly:
- If host selected "Asset Share" → Route to `/session/canvas/{token}` (SessionCanvas)
- If host selected "Section Share" → Route to `/transcript/canvas/{token}` (TranscriptCanvas)

## Solution Design

### Phase 1: Database Schema Enhancement
**Add `CanvasType` column to `canvas.Sessions` table**

**Migration SQL**:
```sql
-- Add CanvasType column to canvas.Sessions table
ALTER TABLE [canvas].[Sessions]
ADD [CanvasType] NVARCHAR(20) NULL DEFAULT 'asset';

-- Add index for query performance
CREATE INDEX IX_Sessions_CanvasType ON [canvas].[Sessions] ([CanvasType]);

-- Update existing sessions to default value
UPDATE [canvas].[Sessions]
SET [CanvasType] = 'asset'
WHERE [CanvasType] IS NULL;
```

**Column Specifications**:
- **Name**: `CanvasType`
- **Type**: `NVARCHAR(20)`
- **Nullable**: `NULL` initially (for backward compatibility)
- **Default**: `'asset'` (SessionCanvas is default behavior)
- **Allowed Values**: `'asset'` | `'transcript'`
- **Index**: Yes (for query performance on UserLanding)
